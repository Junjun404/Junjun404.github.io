## 码制
### 1. 真值、原码、反码、补码
#### 1.1 核心概念定义

| 名称 | 定义说明 | 示例 (以8位二进制为例) |
| :--- | :--- | :--- |
| **真值** | 带有实际正负号的数值。通常用十进制或带符号的二进制表示。 | `+9` 或 `+1001` <br> `-9` 或 `-1001` |
| **原码** | 机器数的一种表示法。**最高位为符号位**（0表示正，1表示负），其余位为真值的绝对值。 | `+9` -> `0000 1001` <br> `-9` -> `1000 1001` |
| **反码** | 机器数的一种表示法。**正数**的反码与其原码相同；**负数**的反码是符号位不变，其余数值位按位取反。 | `+9` -> `0000 1001` <br> `-9` -> `1111 0110` |
| **补码** | 机器数的一种表示法。**正数**的补码与原码相同；**负数**的补码是在反码的末位加1 | `+9` -> `0000 1001` <br> `-9` -> `1111 0111` |

---

#### 1.2 转换规则与关系

#### 1.2.1 正数
对于正数，**真值、原码、反码、补码四者完全相同**（符号位均为0）。
> **公式**：`[X]原 = [X]反 = [X]补`

#### 1.2.2 负数
对于负数，四者的转换关系如下：

1. **真值 $\rightarrow$ 原码**：符号位设为 `1`，数值位保持真值的绝对值不变。
2. **原码 $\rightarrow$ 反码**：符号位保持 `1` 不变，数值位**按位取反**（0变1，1变0）。
3. **反码 $\rightarrow$ 补码**：在反码的基础上，**末位加 1**。
4. **原码 $\rightarrow$ 补码**：符号位保持 `1` 不变，数值位**按位取反后末位加 1**。

> **快捷转换技巧**：
> - **负数原码转补码**：从右向左看，遇到第一个 `1` 之前（包括这个 `1`）保持不变，之后的位全部按位取反。
> - **负数补码转原码**：对补码再求一次补码（即：除符号位外，取反加1），即可还原为原码。

---

#### 1.3 实例演示 (8位机器字长)

#### 示例 A：正数 `+9`
| 表示法 | 计算过程 | 结果 (8位) |
| :--- | :--- | :--- |
| **真值** | 实际数值 | `+1001` |
| **原码** | 符号位0 + 绝对值 `1001` | `0000 1001` |
| **反码** | 正数反码 = 原码 | `0000 1001` |
| **补码** | 正数补码 = 原码 | `0000 1001` |

#### 示例 B：负数 `-9`
| 表示法 | 计算过程 | 结果 (8位) |
| :--- | :--- | :--- |
| **真值** | 实际数值 | `-1001` |
| **原码** | 符号位1 + 绝对值 `1001` | `1000 1001` |
| **反码** | 符号位1不变，数值位 `0001001` 取反 | `1111 0110` |
| **补码** | 反码 `1111 0110` 末位加1 | `1111 0111` |

---

#### 1.4 核心转换流程图

```text
                  (正数)
                 /      \
真值 (+) -----> 原码 <-----> 反码 <-----> 补码
                 \      /
                  (负数)
                   |
                   v
真值 (-) -----> 原码 -----> 反码 -----> 补码
```

### 2. BCD码与格雷码
#### 2.1 BCD码(Binary-Coded Decimal)
1. 8421码
2. 2421码
3. 5421码
4. 余三码

| 十进制数 | 8421码 (权: 8-4-2-1) | 2421码 (权: 2-4-2-1) | 5421码 (权: 5-4-2-1) |余三码(8421码 + 0011)|
| :---: | :---: | :---: | :---: |:---:|
| **0** | 0000 | 0000 | 0000 | 0011 |
| **1** | 0001 | 0001 | 0001 | 0100 |
| **2** | 0010 | 0010 | 0010 | 0101 |
| **3** | 0011 | 0011 | 0011 | 0110 |
| **4** | 0100 | 0100 | 0100 | 0111 |
| **5** | 0101 | 1011 | 1000 | 1000 |
| **6** | 0110 | 1100 | 1001 | 1001 |
| **7** | 0111 | 1101 | 1010 | 1010 |
| **8** | 1000 | 1110 | 1011 | 1011 |
| **9** | 1001 | 1111 | 1100 | 1100 |
> - **2421码**、**5421码**、**余三码**均遵循规则：`5~9` 的最高位为 `1`。
#### 2.2 格雷码（循环码）
- 无权码
- **异或规则：相同为0，不同为1**
- **转换规则：“高位不变，邻位异或”**
e.g.
BCD码：1001 0101
格雷码：11011111
